# YEL3D

Web de **YEL3D**, una tienda de impresiones 3D personalizadas: juguetes, accesorios gaming, expositores de colección, regalos y decoración.

Proyecto de [Dominant System](https://dominant.es/). Desarrollado con IA (Claude Code) bajo mi dirección: defino la estructura y el diseño, reviso el código y hago las pruebas.

## Web publicada

**https://yeray06.github.io/yel3d/**

## Tecnologías

- HTML5 y CSS3
- JavaScript
- SEO on-page: metaetiquetas, Open Graph, datos estructurados (JSON-LD) y sitemap
- GitHub Pages

## Páginas

- `index.html`: portada
- `tienda.html`: catálogo de productos por categorías
- `aviso-legal.html`, `privacidad.html`, `cookies.html`: textos legales
